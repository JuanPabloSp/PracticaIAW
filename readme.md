# Portafolio · Juan Pablo Servin

Portafolio personal de Cloud & DevOps. Página estática (HTML, CSS, JS + Bootstrap 5).

- **Secciones:** Inicio, Sobre mí, Proyectos, Experiencia, Formación y certificaciones, Habilidades, Contacto.
- **Animaciones:** entrada al hacer scroll con `IntersectionObserver`, línea de tiempo, barra de progreso y efecto tilt 3D en certificaciones (respeta `prefers-reduced-motion`).
- **Estructura:** `index.html`, `css/style.css`, `js/main.js`, `img/`.
- **Despliegue:** Vercel.
